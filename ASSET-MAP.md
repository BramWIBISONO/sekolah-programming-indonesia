# SPI Global Image Asset Map

This document serves as the master registry for all image assets used across the Sekolah Programming Indonesia website. It is intended for the Design and Content teams to know exactly which images are needed, their correct paths, and where they belong in the `/public/assets/` directory.

All image files must be placed exactly at the paths specified below.

## Directory Structure & Naming Convention
- **Path structure:** `/assets/[category]/[asset-name].[ext]`
- **Naming convention:** All asset names must use `kebab-case`.
- **Placeholder:** If an image is missing, the system will automatically display a professional placeholder with the exact required path.
